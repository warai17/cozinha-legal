# Cozinha legal pages

Public legal pages for the Cozinha app, served via GitHub Pages.

- `index.html` — privacy policy, linked from the Google Play listing.
- `delete-account.html` — account deletion instructions, required by Play for
  apps that allow account creation.

The app source lives in a separate private repository. Edit the copy at
`legal/privacy.html` there and mirror it here so the two stay in sync.
